# Puente de los Suspiros — guía independiente

Astro estático: inicio en español e inglés, documentos en español. La previsión existente usa Node https durante la compilación y actualización en el navegador; no usa SSR ni server islands.

Instale con la versión declarada en package.json: `pnpm install --frozen-lockfile`. Compruebe con `npm run check` y construya con `npm run build`. `npx wrangler deploy` utiliza src/worker.js y los assets de dist.

Las fotografías locales conservan créditos por archivo y enlaces de origen/licencia junto a cada imagen. Sus fechas históricas no confirman la apariencia u operación actuales. Configuración de análisis: /cookies/.
